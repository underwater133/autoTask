# M7 真机测试清单

> 前置：准备 1~2 台真机（建议：国产 ROM 一台 + 原生/其他 ROM 一台），开启 USB 调试。
> 自动化冒烟脚本见 `scripts/smoke-test.ps1`（安装 APK、启动、抓取服务/闹钟状态、截图）。

## 0. 冒烟测试（每台设备必做）

```powershell
# 在项目根目录执行（自动安装 app-debug.apk 并启动）
.\scripts\smoke-test.ps1
```

检查项：
- [ ] App 安装成功、图标正常（含 Android 13+ 主题图标）
- [ ] 主界面任务列表打开无崩溃
- [ ] 菜单：权限检测 / 执行日志 可进入
- [ ] 新建任务 → 选择应用 → 保存 → 列表出现
- [ ] 前台服务运行（`adb shell dumpsys activity services com.autotask.app` 有 KeeperService）
- [ ] 闹钟已注册（`adb shell dumpsys alarm | findstr autotask`）

## 1. 功能测试矩阵

| 用例 | 步骤 | 预期 |
|---|---|---|
| 单次任务 | 建单次任务，时间设为 2 分钟后 | 到点自动打开目标 App；任务自动停用 |
| 每日任务 | 每日任务，时间设为 2 分钟后 | 每天到点执行；执行记录入日志 |
| 每周任务 | 勾选今天，2 分钟后 | 到点执行 |
| 工作日模式 | 工作日 09:00 任务 | 周一~五执行；周六/周日（非补班）不执行；调休补班日执行 |
| 节假日模式 | 节假日 10:00 任务 | 周末/法定节假日执行；调休补班日不执行 |
| 重启恢复 | 杀进程/重启手机 | 任务闹钟自动恢复（BOOT_COMPLETED） |
| 时间变更 | 改系统时间 | 闹钟重建 |

## 2. 重试机制测试

| 用例 | 步骤 | 预期 |
|---|---|---|
| 目标未安装 | 任务指向已卸载的 App | 立即失败，日志记录"目标应用未安装"；重试 3 次后放弃 |
| 权限缺失 | 关闭悬浮窗权限后触发 | 失败原因"缺少悬浮窗权限"；重试后放弃 |
| 正常拉起 | 任务指向已装 App | 第 1 次成功，日志含"目标应用已进入前台" |
| 重试节奏 | 观察日志时间戳 | 30s / 60s / 120s 递增间隔 |

## 3. 防清理测试（重点，按 ROM 逐项）

| 项 | 小米/Redmi | 华为/荣耀 | OPPO/一加 | vivo/iQOO | 原生 |
|---|---|---|---|---|---|
| 自启动引导页跳转 | 打开"自启动管理"页 | 同上 | 同上 | 同上 | 无此页（跳过） |
| 忽略电池优化 | 设置→应用→省电策略→无限制 | 启动管理→关闭自动管理 | 耗电优化→允许 | 后台耗电→允许 | 直接豁免 |
| 最近任务锁定 | 下拉卡片锁定 | 下拉卡片锁定 | 下拉卡片锁定 | 下拉卡片锁定 | 无 |
| 一键清理后 | 服务仍存活，任务仍触发 | 同左 | 同左 | 同左 | 同左 |
| 息屏 30 分钟后 | 闹钟仍准时触发（Doze 豁免） | 同左 | 同左 | 同左 | 同左 |

## 4. 性能与内存（验收标准）

| 指标 | 目标 | 实测方法 |
|---|---|---|
